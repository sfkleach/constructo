# TEACH: learning Constructo by doing

The TEACH files are short, hands-on tutorials. Each one is meant to be read with
a terminal open beside it: you type the commands, look at what comes back, and
change things to see what happens. They are not the place to look up the exact
rules; the [specs](../specs/) and the [design decisions](../decisions/) are the
reference.

## The main questline

The numbered lessons build on each other, so read them in order. Each lesson
lives in its own folder, together with the example files it uses.

1. [Preferences files](01-preferences-file/README.md): describe the settings
   of a file explorer as types, write a preferences file that matches them, and
   check it with `constructo check`.

## Conventions in the lessons

- A line starting with `$` is something you type. Lines without it are what the
  tool prints.
- Commands are run from inside the lesson's folder, unless the lesson says
  otherwise.
