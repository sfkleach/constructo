# Lesson 02: Reading Constructo Files

## Overview

In lesson 01, we created a preferences file for a file explorer application using Constructo. In this lesson, we will learn how to read in that data and use it.

We will cover:
- How to load a Constructo file, without using any type-definitions and how to
  access its contents.
- How to load a Constructo file using type-definitions and how to access its contents.
- Compare the two approaches: with and without type-definitions and discuss
  their pros and cons.
