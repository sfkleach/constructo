# The Contructo CLI tool

As part of the constructo project, we have a constructo tool that can be
used to:

- validate the syntax of a file that contains a set of constructo data-types
- validate the syntax of file(s) that contain a sequence of constructo data-values
- validate the syntax and type-correctness of one or more data-values files
  against a file of data-types.
- validate the syntax and type-correctness of stdin against a file of data-types.

In the future it will be useful for selecting sub-values from a file or stdin.
However we will need to consider the Constructo path notation.
