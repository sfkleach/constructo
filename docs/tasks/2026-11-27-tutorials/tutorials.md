# Task: Add tutorial content

## Overview

I want to provide tutorial content for beginners who are learning how to use
Constructo. This material will be created in the `docs/teach/` folder and
will be organised into a series of focussed lessons. 

To create a comprehensive learning journey, we identify a "main quest-line" that
guides learners through the essential concepts and skills needed to effectively
use Constructo. This main line is identified by numbering them sequentially
as 01-, 02-, 03-, and so on.

The lessons will be pitched at a level that is suitable for programmers with
some (~6 months) prior programming experience, but who are new to Constructo
and don't necessarily know comparable technologies like JSON or XML beforehand.

## Spike

I started this off from a translation of one of CodeHub's Python Dojo challenges
into Constructo. [This challenge][challenge] is to implement a Tic-Tac-Toe
server using WebSockets. At the moment this is parked in `docs/teach/tictactoe/`
and is waiting to be elaborated into a lesson. 

[challenge]: https://github.com/CodeHubOrg/dojo-ideas/blob/main/problems/2026-11-10-websockets/README.md

I am happy with the translation so far and believe it captures the essence of
the original challenge. However I am waiting for the more basic tutorials to be
elaborated before moving this to a worked example.
